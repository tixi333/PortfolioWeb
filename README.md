# Portfolio Web

Portfolio personal creado para mostrar información sobre mí, mis proyectos y formas de contacto.

## Características

- Diseño responsive para computadora, tablet y celular.
- Modo claro y oscuro.
- Tarjetas para mostrar proyectos.
- Enlaces a GitHub, Instagram y Gmail.
- Íconos de Bootstrap Icons.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- Google Fonts
